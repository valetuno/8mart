# Grand Theft Auto VI — Official 4K Showcase Gallery

A high-performance, animated visual showcase and archival gallery for **Grand Theft Auto VI**, featuring all 37 official 4K/UHD artworks, trailers, key visuals, comic-strip shards, and promotional assets directly ripped from Rockstar Games.

## Features
- **2560x1440 Multi-Plane Holographic Hero**: Real-time 3D parallax across native 4K layers (base key art, comic shards, Roman VI crest, GTA title lettering) driven by smooth mouse interpolation.
- **Snappy 0-Delay Instant Load**: Starts instantly with zero preloader lockup.
- **Custom Roman VI Cursor**: Custom cursor styled as the glowing GTA VI Roman Numeral VI emblem with Vice City magenta/cyan neon aura, hover expansion, and click elasticity.
- **Official YouTube Trailer Integration**: Direct links and embedded theater modal player for official 4K trailers.
- **High-Res Showcase Gallery**: Clean 24-card masonry showcase with smooth zoom tilt.
- **Full-Featured 4K Lightbox**: Smooth modal view with 1x-4x zoom, pan & drag, keyboard shortcuts, preloading, and 1-click downloads.
- **All Assets Included Locally**: All 37 official assets stored in `GTA_VI_HighRes_Images/` + downloadable standalone `.zip`.

## Quick Start
Open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000/index.html`.
